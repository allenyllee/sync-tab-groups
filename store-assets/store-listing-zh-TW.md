# Chrome 線上應用程式商店文案（繁體中文）

## 名稱

Tab Groups Resurrection

## 簡短說明

整理、搜尋、關閉及還原瀏覽器分頁群組，也能讓釘選分頁保留在各自群組中。

## 詳細說明

Tab Groups Resurrection 可依照主題整理大量瀏覽工作階段。

你可以為專案、研究、工作或購物建立群組，在目前視窗切換不同群組，暫時關閉
不使用的群組，之後再依照原本順序與釘選狀態還原。

主要功能：

- 將分頁整理成具名群組
- 關閉瀏覽器後仍可保留並還原群組
- 將釘選分頁保留在所屬群組
- 依名稱或網址搜尋群組與分頁
- 在群組之間移動分頁
- 在目前視窗或新視窗開啟群組
- 使用彈出選單或完整管理頁面整理群組
- 匯入及匯出相容的群組檔案
- 建立附有時間戳記的手動與排程本機備份
- 使用鍵盤快速鍵與右鍵選單

隱私權：

群組資料、分頁網址、標題及偏好設定只保存在瀏覽器的擴充功能本機儲存空間。
本擴充功能沒有分析追蹤、廣告、帳號系統或開發者伺服器，也不會將瀏覽資料傳送
給開發者或第三方。匯出與備份只會透過你主動使用或設定的功能下載。

重要行為：

- 關閉群組時，其中的分頁會實際關閉
- 關閉或切換群組可能會失去未送出的表單內容與上一頁／下一頁紀錄
- 本 fork 不提供雲端或跨裝置同步

關於本 fork：

Tab Groups Resurrection 是 Sync Tab Groups 的獨立維護版，主要支援 Chromium
與 Manifest V3。原始專案由 Eric Masseran（Morikko）開發；本 fork 採用不同名稱
以避免混淆，且不由原作者維護或背書。
