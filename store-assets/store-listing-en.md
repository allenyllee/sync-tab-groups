# Chrome Web Store listing

## Product name

Tab Groups Resurrection

## Summary

Organize, search, close, and restore browser tab groups, including their pinned
tabs.

## Category

Workflow & Planning

## Detailed description

Tab Groups Resurrection helps you keep large browsing sessions organized by
topic.

Create groups for projects, research, work, shopping, or anything else. Switch
the current window from one group to another, close groups you are not using,
and restore them later with their tab order and pinned tabs intact.

Key features:

- organize tabs into named groups;
- close and restore groups across browser restarts;
- keep pinned tabs inside their own groups;
- search groups and tabs by name or URL;
- move tabs between groups;
- open a group in the current window or a new window;
- manage groups from the popup or full-page manager;
- import and export compatible group files;
- create timestamped manual and scheduled local backups;
- use keyboard shortcuts and context-menu actions.

Privacy:

Your group data, tab URLs, titles, and preferences stay in browser-local
extension storage. The extension has no analytics, advertising, account system,
or developer-run server, and does not transmit your browsing data to the
developer or third parties. Exports and backups are downloaded only through the
features you control.

Important behavior:

- tabs in a closed group are actually closed;
- closing or switching a group may discard page session state such as unsaved
  form input and page back/forward history;
- this fork does not provide cloud or cross-device synchronization.

About this fork:

Tab Groups Resurrection is an independently maintained Chromium Manifest V3
fork of the open-source Sync Tab Groups extension originally created by Eric
Masseran (Morikko). It uses a different name to avoid confusion and is not
maintained or endorsed by the original author.
